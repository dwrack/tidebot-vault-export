# Incident Report Steps
**Something went wrong. Handle it in this order.**

---

1. **Ensure passenger safety first.** Stop the vehicle. Check if anyone is hurt. Keep everyone calm and seated.

> [!warning] If there is a collision or any injury, call 911 immediately. Do not attempt to move an injured person unless they are in immediate danger (fire, traffic).

2. If safe to do so, move the vehicle out of active traffic lanes. Turn on hazard lights.
3. Administer first aid if needed and you are trained to do so.
4. Contact management immediately. Call, don't text. If no answer, call the backup contact.
5. If there was a collision with another vehicle, person, or property:
   - Exchange information: names, phone numbers, insurance, license plates.
   - Get contact info from any witnesses.
   - Do NOT admit fault or make statements about cause.
6. Take photos of everything: vehicle damage, scene, road conditions, traffic signals, injuries (with consent), other vehicles involved.
7. File a police report if required (any collision, any injury, any property damage). Get the report number.
8. Report to insurance. Management will handle this, but provide them all documentation.
9. File an internal incident report the same day. Include:
   - Date, time, location
   - Driver name
   - Number of passengers
   - What happened (factual, not opinion)
   - Injuries (if any)
   - Police report number (if filed)
   - Photos attached
   - Witness contact info
10. Do not post about the incident on social media or discuss details with anyone outside the company.

> [!tip] Even "minor" incidents get documented. A passenger bumps their head getting off, someone twists an ankle stepping down, a mirror gets clipped. If something happened, write it up. Undocumented incidents become legal surprises later.
