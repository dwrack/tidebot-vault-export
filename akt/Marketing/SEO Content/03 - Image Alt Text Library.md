## Filename convention going forward

When uploading new images to the media library, use:

```
descriptive-keyword-rich-name.jpg
```

Examples:
- `austin-skyline-kayak-tour-lady-bird-lake-aerial.jpg`
- `bat-bridge-kayak-tour-sunset-paddlers.jpg`
- `paddle-board-rental-lady-bird-lake-austin.jpg`

Never upload `IMG_4521.jpg` or `DJI_0042.JPG` directly. Rename first.

## Alt text rules

- Describe what's in the image, not what you wish it conveyed
- Include "Austin", "Lady Bird Lake", or a tour-name keyword when natural
- Don't keyword stuff. One target keyword per alt text, max
- Keep under 125 characters
- Don't start with "Image of" or "Photo of"
