# NKST — Guide Onboarding Matrix
*Created: July 2026*

> The existing [[SOPs/Quick Ref/Contractor Onboarding Checklist]] is the step-by-step. This matrix adds what that checklist doesn't have: who owns each stage, what "done" looks like, the hard gates, and where the new accountability system (photos + audio logs) gets trained in. A guide who finishes this matrix should never be surprised by an accountability flag, because they practiced the whole proof routine before their first solo.

---

## Stage Matrix

| Stage | What happens | Owner | Deliverable / proof | Hard gate before next stage |
|---|---|---|---|---|
| **0. Culture** | Read "How We Run Things" + [[Brand Story & Values]] | Guide | Confirms read; ops manager asks 2-3 questions about it in first conversation | None, but nothing else starts until this is read |
| **1. Paperwork** | ICA (DocuSeal), Exhibit A rate sheet, Exhibit B equipment/photo standard, W-9, DL photo, CPR cert (or timeline), FCRA + drug consent, payment info | Ops manager sends, guide completes | All docs in guide's file per [[Legal/Independent Contractor Agreement — Template & Legal Analysis]] file system | **No shadow shift without signed ICA + Exhibit B** |
| **2. Systems access** | Slack invite (tour log channel), FareHarbor login, GHL contact created with tag `guide-new`, TideBot intro | Ops manager | Guide posts a test message in Slack, opens FareHarbor manifest | Guide can navigate both |
| **3. Base orientation** | Walk 1407 Piety St: equipment storage, van, trailer hitch/strap/backing demo, PFD rack, MiraZyme station, gas card, lock-up routine | Ops manager or senior guide | Guide does the full lock-up once, observed | None |
| **4. Shadow shifts (2-3 tours)** | Ride along, observe full cycle. **On each shadow, the new guide shoots the post-tour proof set (2 videos + 2 photos) and posts it**, senior guide checks framing | Senior guide | Photo sets posted from every shadow shift; debrief notes after each | Senior guide says ready to co-lead |
| **5. Co-guide shifts (1-2 tours)** | New guide leads safety briefing, PFD fitting, FareHarbor check-in. **Records the pre-tour and post-tour audio logs themselves** | Senior guide | Audio logs 1 + 3 posted, proof set posted, senior guide fills gaps | Senior guide sign-off |
| **6. Pre-solo verification** | Cross-check: ICA + Exhibit B signed, CPR current, DL verified, FareHarbor works, handbook quiz + vehicle quiz passed, acknowledgement form signed | Ops manager | All ✅ in [[Guides/Guide Roster & Compliance Tracker 2026]] | **All items green. No exceptions.** |
| **7. First solo** | Management on call the whole tour. Full accountability routine runs live: audio logs, proof set, GHL text | Guide, with ops manager on call | Complete tour thread in Slack (2 audio logs + 2 videos + 2 photos), same-day debrief | Debrief done |
| **8. Sign-off** | Solo sign-off logged, GHL tag flips `guide-new` → `guide-active`, guide enters weekly check-in rotation and deep-clean rotation | Ops manager | Sign-off date in roster tracker | Guide is fully live |

---

## What "Trained on Accountability" Means

By the end of stage 5, the guide has personally, with someone watching:

- Posted the full proof set (interior pan video, PFD rack photo, dash video, locked gate photo) at least 3 times (shadows + co-guides)
- Recorded pre-tour and post-tour audio logs at least once
- Done the pickup inspection and knows the rule: flag a dirty handoff with a photo before touching anything, or own the condition yourself
- Hung and sprayed PFDs at the rack
- Run the full lock-up (van, container, gate)

So the accountability matrix is never news to them. It's just the routine they already learned.

---

## First-Week Message (After Sign-Off)

> "Hey [Name], you're official. Couple things now that you're solo: TideBot will nudge you before and after each tour for the logs and the proof videos/photos, and once a week you'll get one quick question from us, no forms, just staying connected. If you ever show up to a van that's not right, photo it and drop it in Slack before you do anything else. That protects you. Welcome aboard."

---

## Timing Expectations

Paperwork to first solo typically runs 2-3 weeks depending on tour volume for shadows. Don't compress it below 2 shadow + 1 co-guide even for experienced guides from other outfits; they still need our proof routine, our launch sites, and our trailer.
