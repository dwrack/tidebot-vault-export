# End-of-Day Sign-Off

Nothing leaves the site unsecured. Nothing goes unreported.

---

1. Secure all vessels: lines tied, engines off, battery switches off
2. Confirm navigation lights are off on every vessel
3. Store all loose equipment: radios, speakers, coolers, signage
4. Lock any storage compartments or hatches
5. Clean the dock and boarding area
6. Empty all trash from the site
7. Walk the grounds one final time for anything out of place
8. Report any issues discovered during the day to Jeffrey via Slack
9. File any outstanding incident reports (must be same-day)
10. Confirm all keys and radios are accounted for and stored

> [!warning] If an incident report is still pending from today, it does not wait until tomorrow. File it before you leave.

> [!tip] If something broke or ran low today and you didn't have time to fix it, flag it in Slack tonight so tomorrow's crew knows.
