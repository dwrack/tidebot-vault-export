# IG Library — Index and Naming Guide

Every video ever posted to @nolapartybarge (785 posts pulled 2026-09-10, 503 videos
downloadable). Full post metadata (captions, likes, permalinks, IDs) in `_catalog.json`.

## How files are named

`YYYY-MM-DD_<likes>L_<caption-slug>_<postid>.mp4`

So `2024-05-04_33907L_rules-are-rules..._574847.mp4` = posted May 4 2024, 33,907
likes. Sort by name = chronological. The likes number is the proven-performance
signal; anything over ~100L earned it.

**`zz-NPB-ONLY-gator-contact_` prefix = gator feeding/baiting/touching content.**
Fine for NPB's own accounts (David's call, Sep 2026). NEVER for @admirenola or any
sibling brand — "we never bait" is Admire's differentiator. 5 files, sorted last
on purpose so they aren't grabbed for the wrong brand.
