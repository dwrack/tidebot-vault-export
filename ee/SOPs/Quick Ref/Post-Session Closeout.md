# Post-Session Closeout
**Reset the space so the next session feels like the first one of the day.**

---

1. Confirm all guests have exited the sauna and the dock area. Do a headcount out.
2. Collect used towels and stage for laundry.
3. Power down or adjust the sauna heater per procedure (full shutdown if last session, adjust if another session is coming).
4. Empty and rinse cooling buckets. Refill with fresh water if another session follows.
5. Wipe down sauna benches and interior surfaces.
6. Clean the lounge/deck area: pick up any bottles, trash, personal items.
7. Check for any personal items left behind. Contact the guest immediately if you find something.
8. Ask departing guests for a review: "If you enjoyed the experience, a Google review means a lot to us." Light touch, not pushy.
9. Note any guest feedback worth sharing: drop it in the group chat or Slack.
10. If another session is coming, verify sauna temp is recovering and all supplies are reset.

> [!tip] The turnaround between sessions sets the tone. If a guest arrives to a messy space with used towels around, you've already lost the premium feel before they even get in the sauna.
