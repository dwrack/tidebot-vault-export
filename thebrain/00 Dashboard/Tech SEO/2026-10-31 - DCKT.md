# Tech SEO: DCKT (doorcountykayaktours.com), 2026-10-31

Staged report, nothing changed on the live site. Filed per brand because other brands may run the same day. Measured 2026-10-31: PageSpeed Insights v5 (with API key), curl redirect checks, full sitemap crawl (121 URLs), HEAD check of 261 internal link targets, robots and sitemap fetch.

**Verdict: crawl health is good, speed is poor.** Every sitemap URL returns 200, robots and sitemap are sound. Mobile performance scores 30 to 36 on all four pages tested, which is a theme-level problem shared with the other FareHarbor sites.

## robots.txt and sitemap

- robots.txt: User-agent * disallows only /edit/, /fhbr-console/, /cdn-cgi/. A block list of scraper bots (MegaIndex, Baidu, Yandex, SeznamBot, etc.) is disallowed. AI crawlers (GPTBot, ClaudeBot, etc.) are not blocked. Sitemap line present. /llms.txt returns 200 (content not reviewed).
- sitemap.xml is an index: page-sitemap (35), activity-sitemap (32), post-sitemap (54) = 121 URLs, all 200.
- Sitemap hygiene: junk and thank-you pages are listed: /claude-ads-mcp-2/, /contest-giveaway-entered/, /e-bike-contest-giveaway-entered/, /unsubsribe/, /how-was-your-tour/, /job-application/, /data-deletion/, /opt-out-preferences/, /download-your-kayak-photos/. 18 utility pages share the generic meta "Discover what Door County Kayak Tours is all about".
- No noindex tags found on any sitemap URL (checked robots meta on all 121).
