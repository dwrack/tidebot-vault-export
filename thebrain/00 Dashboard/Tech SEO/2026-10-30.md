# Tech SEO Audit - October 30, 2026

Measured, nothing changed. Free sources only: PageSpeed Insights (keyed, mobile + desktop), curl redirect/robots/sitemap/link checks, GSC MCP. Homepage plus main booking/tours page per site. Raw Lighthouse JSON kept out of the note.

**Headline:** all 8 sites score under 50 on mobile for the homepage (30 to 45). The cause is shared: the FareHarbor / WP-VIP theme ships 1.2 to 2.8 MB of unused JavaScript and 4 to 11 MB total page weight. Lab LCP is 9.5 to 38 s on mobile. Real-user (CrUX) LCP is still fine (1.4 to 2.3 s) on the sites that have field data, so this is lab/throttled-phone pain and a ranking-signal risk, not an outage.

## Redirects

- Every site: one clean 301 to the canonical host from https, but `http://` on the non-canonical host takes 2 hops (http to https to canonical). Same on all 8, normal for this stack. P3.
- Canonical host: www on AKT, DCKT, GT; bare domain on NPB, NKST, BBK, HPB, NBB. GSC properties for NPB and NBB are the www version while the site resolves to bare, so confirm the Domain property is what's used for reporting (sc-domain exists for NPB, HPB).

## Broken links

- Homepage + booking page internal links (about 15 to 50 per site): **0 real broken links on all 8.** Only 404 hit was `/cdn-cgi/l/email-protection`, a Cloudflare email-obfuscation artifact that 404s for curl, not a real break. Not counted.
- Sitemap sample (40 URLs per site, random): all 200 except redirects listed under sitemap below.

## robots.txt and sitemap

- No errors on any site. robots.txt 200, allows the site, blocks only /edit/, /fhbr-console/, /cdn-cgi/ and a list of junk bots. Each robots.txt references `/sitemap.xml` on the canonical host. sitemap.xml is a sitemap index (page, activity, post) and returns 200 everywhere.
- Sitemap URL counts: NPB 135, NKST 155, BBK 46, AKT 79, HPB 42, DCKT 121, NBB 37, GT 50. No host mismatches.
- Stale URLs in sitemaps (301s): `/privacy-policy/` redirects to `/privacy-statement-us/` and is still listed on NPB, NKST, BBK, HPB, GT. GT is worse: 7 of 40 sampled sitemap URLs redirect, including `/austin-tx/austin-paddleboard-tours/*` (moved to `/austin-paddleboard-tours/*`) and `/jobs/`, `/q-a/`, `/gift-certificates/` which redirect to the homepage (soft-404 pattern). P2 for GT, P3 elsewhere.

## Prioritized fix list

**P1 (speed, mobile ranking signal, every site)**
1. Cut unused JavaScript (1.2 to 2.8 MB per page). Biggest offenders from the NBB trace: three FH theme bundles on the cloudfront `static/cache/js/output.*.js` (380 KB + 188 KB + 99 KB wasted), `gtag/js` (96 KB wasted), and `fareharbor.com/static/dist/honeycomb-sdk-bundle.js` (80 KB wasted). Defer/lazy-load non-critical bundles and load the FH SDK on interaction.
2. Reduce page weight and hero image cost. NBB home 11.1 MB with a 38 s LCP is the worst; NKST (9.6 MB) and HPB (8.9 MB) next. Serve right-sized WebP/AVIF hero, and never lazy-load the LCP image.
3. Cut main-thread blocking (TBT 1.5 to 4.4 s). Same JS fix. NBB booking page loses about 6 s to unused JS alone; AKT home about 2.3 s.

**P2**
4. DCKT: fix layout shift (CLS 0.129 home mobile, 0.184 booking desktop). Reserve space for images/embeds.
5. NPB: field CLS on desktop homepage is SLOW (real users). Find the shifting element.
6. GT: clean sitemap (7/40 redirect) and drop dead pages; GT booking page (80 mobile) is fine, homepage (45, LCP 9.5 s) is the problem.
7. BBK: add/verify Search Console property.

**P3**
8. Remove `/privacy-policy/` from sitemaps (NPB, NKST, BBK, HPB, GT); it 301s.
9. http on the non-canonical host takes 2 hops.
