# Tech SEO: Cave Point Paddle & Pedal (cavepointpp.com), 2026-10-31

Single-brand run (CPPP only). Measured live 2026-10-31. PSI v5 via the keyed API (the keyless quota was exhausted). Measure and report only, nothing was changed. The CPPP vault copy of the content audit is `Cave Point Paddle and Pedal/SEO Content/SEO Audit 2026-10-31.md`.

## Verdict

Crawlable and clean on canonicals, sitemap and HTTPS, but slow: mobile performance scores 34 to 56 and the flagship tour page has a 19.7 s lab LCP, driven mostly by third-party widgets (Elfsight reviews, OpenCX chat, TripAdvisor, YouTube) and heavy images. Field data (CrUX) is not available for this origin (too little traffic), so these are lab numbers.

Thresholds: LCP good under 2.5 s, poor over 4 s. TBT poor over 600 ms. CLS poor over 0.25, so the Whitefish guide (0.201) is in the needs-improvement band.

What is causing it (home, mobile):
- Main-thread work 9.5 s, JS bootup 6.3 s, 1,780 KiB unused JavaScript, total page 6.4 MB.
- Elfsight All-in-One Reviews: 3.4 s of bootup, 473 KB. Largest single cost on every page tested.
- OpenCX chat widget: 663 KB script, 0.8 s bootup, loaded as `unpkg.com/@opencx/widget@latest` (an unpinned version in the page, resolves to 5.7.0 today).
- Images: `cave-point-county-park.png` 1.1 MB, `full-moon-paddle.png` 362 KB, hero `cpppheader.jpg` 230 KB. PNGs for photos.
- Flagship tour page also loads a YouTube player (483 KB) and a 884 KB hero JPG. The PSI run also reported a 6.3 s time to first byte for that URL. A plain curl sees 0.09 s (edge cache hit) and 0.35 to 0.87 s on an uncached URL, so treat the TTFB figure as a cold-lab artifact, but re-test.

Lighthouse non-performance fails on the home page: 6 "LEARN MORE" links (link-text), a nav anchor that is not crawlable, images without alt, an unsized footer image, 1 deprecation warning, 1 third-party cookie (FareHarbor cart embed), and best-practices score 58 from console/inspector issues.

## robots.txt and sitemap

- robots.txt: allows everything except `/edit/`, `/fhbr-console/`, `/cdn-cgi/` and blocks about 16 scraper bots (Yandex, Baidu, Seznam and others). Nothing blocks Googlebot or content. Sitemap line present.
- sitemap.xml: index with `page-sitemap.xml` (17), `activity-sitemap.xml` (25), `post-sitemap.xml` (40) = 82 URLs, all return 200 or 301 (5 are redirects, above). Blog posts are all included; no `noindex` pages found.
- Meta robots on pages: 81 pages `index,follow`, **1 page `index,nofollow`: `/door-county-boat-tours/`** (P1 for link equity, a money hub told not to pass links).

## Prioritized fix list

P1
1. `/door-county-boat-tours/` meta robots `index,nofollow`: change to `index,follow` (SEO field on that page). 
2. Defer or remove the Elfsight reviews widget on the home page and flagship tour page (or load it on scroll / after interaction). Biggest single speed win, TBT 3.4 s.
3. Flagship `/kayak-tours/cave-kayak-tour/` LCP 19.7 s: swap the 884 KB hero for a 150 to 250 KB JPG/WebP, lazy-load the YouTube embed (use a thumbnail facade), re-test the TTFB.

P2
4. Pin the OpenCX widget version instead of `@latest`, load it after interaction. Also check which OpenCX org it points at: the vault notes say CPPP is not wired into OpenCX separately from DCKT, so chats may land in the sibling org.
5. Convert `cave-point-county-park.png` (1.1 MB) and `full-moon-paddle.png` (362 KB) to JPG at about 1600 px wide / 300 KB.
6. Remove the 5 redirecting URLs from the sitemap and fix the `/unique-experiences/` link.
7. One-hop http://www redirect; confirm the GSC canonical split on the homepage and update the GBP website link to `https://cavepointpp.com/`.
8. Whitefish guide CLS 0.201: reserve space for the 3 shifting blocks (H2/paragraphs below the hero, probably images without dimensions).

P3
9. Replace "LEARN MORE" anchors on the homepage with descriptive text; give the nav anchor an href.
10. Add width/height to the unsized footer image; add alt text to images that lack it (1 to 5 per page).
11. Update links that point to 301 URLs (2019 permalinks, short tour URLs) to the live URL.

## Affects all FH sites (shared FareHarbor / WP-VIP theme: fix once)

Checked on CPPP; the DCKT and NPB home pages also reference Elfsight and OpenCX, so these likely apply to every `*.fareharbor.site` brand but I only measured CPPP. Verify per brand before filing with FareHarbor.

1. Third-party widget weight: Elfsight reviews (found on cavepointpp.com, doorcountykayaktours.com and nolapartybarges.com home pages) and the OpenCX chat script are in every home page. Both are heavy main-thread cost. Ask FareHarbor whether the theme can load the Elfsight/chat scripts after interaction.
2. Theme JS bundles (`/_static/...` and the cloudfront `output.*.js`, about 1 MB combined) plus the widgets leave 1.78 MB of unused JavaScript on the home page (Lighthouse estimate).
3. Redirecting/duplicate paths in the sitemap (`/gift-certificate/`, `/privacy-policy/`, `/door-county-tours/`, `/fall-foliage-tour/` pattern): the theme sitemap lists URLs that 301. Probably an activity-slug issue, ask FareHarbor to exclude redirected slugs.
4. Content Security Policy header allows `'unsafe-inline'` and `'unsafe-eval'` with wildcard `https:` for scripts (Lighthouse best practices flag). Low SEO impact, but it keeps best-practices at 58.
5. A generic-text link pattern (tour cards use "LEARN MORE") is a theme template; a descriptive `aria-label` or anchor text pattern would fix it everywhere.
6. Every page has at least one image without alt text (1 per page on most of the 82 URLs, likely a shared header/footer element, not confirmed which).
7. Schema: tour (activity) templates output only BreadcrumbList. TouristTrip/Product + Offer + AggregateRating would need to come from the theme.
