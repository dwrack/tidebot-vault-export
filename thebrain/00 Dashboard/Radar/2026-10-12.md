### 3. Atticus: talk to Claude Code instead of typing at it
- **What changed:** A free, open-source Mac app (Show HN, 30 points) that lets you hold a hotkey, talk, and it routes simple stuff locally in under a second or hands anything complex to `claude -p`, no API key, runs on an existing Claude Pro or Max plan. At least 5-6 similar Claude-voice projects surfaced on GitHub the same week (claude-voice-plugin, jarvis, mcp-claude-say, voice-to-claude), this is clearly a pattern forming, not a one-off toy.
- **Who it's for:** Anyone who lives in Claude Code all day and wants hands-free control some of the time.
- **Why now:** `claude -p` has existed for a while, what's new is a clean, zero-setup wrapper that makes voice-driving an agent session something you can just install tonight instead of build yourself.
- **Own-the-ground angle:** Fully open-source, runs locally on his own Mac, built directly on the tool he already pays for. Nothing rented here at all.
- **Cheap first test:** `git clone` it tonight, hold the hotkey, and steer one real task by voice instead of keyboard, check tomorrow's radar brief, or draft a reply, and see how far "hands-free Claude Code" actually gets in practice.
- **Fit:** Directly closes the desk half of the desk<->mobile gap he's been chewing on, this is the cheapest possible first step toward that, before chasing anything hardware-based.
