### 2. Bonsai 2 27B — real reasoning in 5.9GB, runs offline
- **What changed:** Prism ML shipped a 27B-parameter model, ternary-compressed to a 9x smaller footprint (5.9GB), with a 262K token context and genuine multimodal capability, small enough to run on ordinary hardware with no internet connection.
- **Who it's for:** Anyone doing repeated, cheap inference where an API bill or a connectivity requirement is the actual constraint, not the model's intelligence.
- **Why now:** Compression finally caught up to capability. A model this small used to mean a model that was also dumb; this one isn't.
- **Own-the-ground angle:** Open weights, self-hosted, no vendor, no per-call bill. Runs on hardware David already owns.
- **Cheap first test:** Download it and point it at something already on his plate: classifying Blink cam stills for the marina fuel watch, or triaging boatcam footage, both currently either manual or running through a paid API. See if a free local model actually gets the job done.
- **Fit:** Fits his edge (real operations generating real footage/data at his marinas) better than it fits a generic SaaS company. It's also the kind of thing that works when the boat has no signal.
- Source: [Prism ML](https://prismml.com/news/bonsai-2-27b) · scores: newly-possible 4/5, momentum 2/5, own-ground 5/5, fit 4/5, run-with-it 4/5

### 3. Notion Skills API — your agent's instructions become portable
- **What changed:** Notion shipped a Skills API, three endpoints that expose team-written "skills" (spec-compliant instruction files) so they can sync into a GitHub plugin marketplace and be read by Claude, ChatGPT, or Vercel's skills CLI. A skill written once stops being locked to one agent's format.
- **Who it's for:** Anyone with a growing pile of hand-written agent instructions who doesn't want each one rebuilt per tool.
- **Why now:** The "skill" is starting to formalize as its own portable unit, the way a function or a package did for code.
- **Own-the-ground angle:** David's actual moat is exactly this shape: dozens of hand-built Claude skills (radar, morning-brief, google-ads, kid-coach) that are the real IP behind this whole setup, already living as plain files he owns, not rented from any platform.
- **Cheap first test:** Try `npx skills` against one existing skill this week and see if making it portable (so it could run the same way on a different agent surface) is worth the plumbing, without giving up ownership of the source files.
- **Fit:** Directly relevant given how skill-dependent his whole operation already is; validates investing more in the skill library rather than one-off prompts.
- Source: [Notion](https://www.notion.com/blog/a-skills-library-for-every-agent) · scores: newly-possible 3/5, momentum 3/5, own-ground 4/5, fit 4/5, run-with-it 4/5
