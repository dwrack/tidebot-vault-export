### 2. Perplexity Portable Computer — fully local AI agent, zero token costs
- **What changed:** Perplexity and Nvidia shipped an agent stack (model, harness, tools, connectors, sandbox) that runs entirely on hardware you own. No token billing. Data stays local unless you approve an escalation to the cloud.
- **Who it's for:** Anyone running AI-heavy workflows at real volume who's tired of the token meter, or who has data he'd rather not hand a vendor.
- **Why now:** This is the first big-name vendor to ship the whole stack pre-packaged for local hardware, not just a raw model you wire up yourself. Runs on any RTX GPU with 24GB+ VRAM — roughly a used 3090 or newer — or an Nvidia DGX Spark. Windows support lands in September; no Apple silicon roadmap yet.
- **Own-the-ground angle:** About as ownable as it gets — no billing relationship, no API that can change price or vanish, data never leaves the box by default.
- **Cheap first test:** Price a used RTX 3090 (24GB, roughly $700-900 secondhand) and point one always-on job at it — a nightly Google Business Profile review scan across the 12 businesses, say — and see if local quality clears the bar to retire that cloud API call.
- **Fit:** Moderate. Running a GPU box isn't his edge, but the cost/ownership math matters given how many AI-touched jobs already run across the portfolio.
- Source: [VentureBeat](https://venturebeat.com/infrastructure/perplexity-partners-with-nvidia-to-launch-portable-computer-a-fully-local-ai-agent-with-zero-token-costs) · scores: newly-possible 5/5, momentum 5/5, own-ground 5/5, fit 3/5, run-with-it 3/5
