### 1. llama-modchip: a 284B model on ordinary RAM, no GPU
- **What changed:** An open-source project memory-maps a 284B-parameter DeepSeek model so it runs on 64GB of plain system RAM with no GPU at all. Hit #6 on HN's front page (442 points, 196 comments) the day it posted.
- **Who it's for:** Anyone who wants frontier-scale local inference without a $20K GPU rig.
- **Why now:** Model-size-to-hardware ratios that needed a data center 18 months ago now run on a beefy Mac Mini or a used workstation. That's the line crossing.
- **Own-the-ground angle:** Runs entirely on hardware you own, zero API dependency, zero vendor that can cut you off or change pricing. This is as own-the-ground as AI gets.
- **Cheap first test:** Clone it on the Intel loop box (or a spare partition on mbp-2) and benchmark one real recurring job from the stack, caption drafting or log triage, against what that job costs through an API today.
- **Fit:** Ties directly into the parked night-shift local model project. Doesn't close the desk<->mobile gap, but it's a genuine cost and resilience play for the automation fleet.
- Source: [GitHub](https://github.com/synchopate/llama-modchip) · scores: newly-possible 5/5, momentum 3/5, own-ground 5/5, fit 3/5, run-with-it 3/5

### 2. OpenRouter Auto Code: cheap, good-enough model routing, automatically
- **What changed:** OpenRouter shipped a next-gen Auto Router and a coding-specific Auto Code router. It picks the model that clears a quality bar for the least money per request. OpenRouter's own benchmarks claim Opus-5.5-level coding output at 74% lower cost than routing to Opus directly.
- **Who it's for:** Anyone running a lot of small-to-medium LLM calls where paying top-model prices for every call is waste.
- **Why now:** Model routing has existed for a while, but this is the first version good enough that the quality trade-off is small enough to actually trust on real work, not just toy benchmarks.
- **Own-the-ground angle:** It's a durable paid API with a stable contract, same category as Twilio. You're not locked into any one model; the router is the product, so you keep your own calling code.
- **Cheap first test:** Point one cheap, high-volume background loop, an Idea Radar pass, a Slack summarizer, a GBP-refill draft step, at `openrouter/auto-code` for a week. Diff cost and output quality against whatever it runs on now.
- **Fit:** Any coder could wire this up, but at your scale (dozens of always-on loops across 12+ businesses), a 74% cost cut on the cheap-call tier adds up fast and is the kind of operational lever an operator notices and a pure engineer might not bother chasing.
- Source: [OpenRouter](https://openrouter.ai/blog/announcements/auto-and-auto-code-routers/) · scores: newly-possible 4/5, momentum 3/5, own-ground 4/5, fit 3/5, run-with-it 5/5
